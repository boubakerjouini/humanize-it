Nom & Mission

HumanizeIt

Rendre le contenu IA indétectable, sans sacrifier la voix de l'auteur.

Tagline principale
"Write with AI. Sound like you."
Tagline secondaire
"AI speed. Human quality."

Personnalité de la marque

Précis
Chaque diagnostic est factuel, mesurable, actionnable. Pas de vagues appréciations.
Transparent
L'algorithme n'est pas une boîte noire. La confiance se construit par l'explication.
Minimal
Chaque élément présent a une raison d'être. L'outil s'efface devant le texte.
Direct
Pas de marketing vague. HumanizeIt dit exactement ce qu'il fait, et à quel prix.
Empowerant
Donne des outils pour que l'auteur prenne de meilleures décisions. L'autonomie d'abord.

Code Block — Style officiel

const analyzeText = async (text: string) => {
  // Run 24 AI pattern detectors locally
  const score = await scorePatterns(text);
  return {
    humanScore: score.overall, // 0–100
    patterns: score.detections,
    suggestions: generateFixes(score),
  };
};

Règles fondamentales

✅ Animations purposeful — chaque animation a une raison fonctionnelle
✅ Respecter prefers-reduced-motion: reduce
✅ Stagger lists : +100ms par item (max 5 items staggerés)
❌ Pas d'animations en boucle sauf le spinner de loading
❌ Pas de transitions sur height: auto
❌ Hover states > 150ms — au-delà ça devient lent

CTAs

✅ DO — Verbe + bénéfice

"Humanize Now"

"Copy Result"

❌ DON'T — Générique

"Get Started"

"Sign Up"

"Learn More"

"Submit"

Error Messages

✅ DO — Clair + solution

"Text too short. Paste 100+ words for an accurate score."

"Analysis failed. Check your connection and retry."

"Session expired. Log in again to continue."

"Free limit reached. Upgrade to analyze unlimited text."

❌ DON'T — Jargon/vague

"Error: insufficient input"

"Something went wrong"

"401 Unauthorized"

"Quota exceeded"

Succès & Feedback positif

✅ "Your text looks human. Score: 94/100."
✅ "All AI patterns removed. Ready to submit."
✅ "Human score improved from 42 → 89. 🎉"
